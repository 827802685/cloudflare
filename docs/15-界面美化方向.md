# 15 · 界面美化方向（第二轮，先定纲再动手）

## 0. 上一轮为什么"更没做一样"

§9 那轮改的是色板深浅、字宽、毛玻璃、2px 轨道上色——全在"眯眼才分辨得出"的幅度里，底栏一多出来反而像退步。这一轮的验收标准改成一条硬指标：**改完后你不用对比截图，扫一眼就能说出至少三处不一样**。说不出就算白做。

能被判"看见"的只有四种改动，按显眼程度排：① 图标体系换血（emoji → 成套线性图标）② 首屏版式重排（读数表大表盘）③ 界面开屏动效（仪表自检）④ 字阶对比拉大。前三个都在这一轮的名单上；色板微调这种降级为顺手项，不单独宣称。

## 1. 定位一句话

**Handheld edge-network readout instrument —— 一台能揣兜里的边缘网络读数仪。**
用户是盯自己小网络的运维者，不是逛后台的管理员。每个界面元素都得像是仪表上的东西：表盘、走纸、通道面板、批注条。凡是"网页感"的装饰（大圆角卡片阵列、营销式渐变、emoji 当功能图标）都是失真。

## 2. 可见改动清单（本轮的全部范围）

### 2.1 图标体系：拆掉 emoji（最显眼的一笔）

现状：底栏 `▦ ◈ ⛁ ◎ ⚙`、Worker 动作宫格 `🗂 🚀 ⚙️ 🔒 ⏱ 📈 🔁 🛰`、标题 `📊` —— 系统 emoji 跨设备形状/配色全不受控，橙色 emoji 跟 CF 橙互相抢，是"网页感"最大来源。

方向：内置一套 **16 格线性 SVG 图标**（stroke 1.5、currentColor、24 视口），直接写进 `main.css` 同级的 `icons.ts`（导出组件或 `<svg>` symbol sprite），不引第三方库。语义逐格定：

| 位置 | 现在 | 换成 |
| --- | --- | --- |
| 底栏·域名 | ◎ | 地球仪经线（圆 + 两弧） |
| 底栏·计算 | ◈ | 闪电在方框（边缘节点） |
| 底栏·看板 | ▦ | 四格表盘窗 |
| 底栏·数据库 | ⛁ | 三层堆盘 |
| 底栏·Zero Trust | ⛨ | 盾 + 一道锁孔 |
| 顶栏·设置 | ⚙ | 齿轮（线性重绘） |
| 动作宫格 8 格 | 🗂🚀⚙️🔒⏱📈🔁🛰 | 列表/火箭/滑杆/锁/时钟/脉冲线/环箭头/天线，同套 stroke |

规则：图标一律吃 `currentColor`，激活态只变色不变形；标题里的 `📊` 这类纯装饰 emoji 直接删，不替换。

### 2.2 看板首屏：从"8 个等大格子"改成"主表盘 + 走纸带"

现状：8 格 tile 平铺，信息密度均匀 = 视觉重点为零。

方向（ASCII 线框）：

```
┌ 读数仪 · 主表盘 ──────────────────┐
│ 总请求        ‹24h│ 7d │30d›      │
│                                │
│    21,529        ▲ +21.9%       │   ← 数字上 44px 超大表头
│    次 · 过去 7 天 · 至 02:29     │   ← 读数行下一律挂口径小字
│ ── 7 日走纸：峰值 5,852 ──256──  │   ← 把现在图表区的曲线缩成一条
└────────────────────────────────┘   32px 高的迷你 sparkline 嵌进表盘底
  副表盘 ×4（横滑）: 出口带宽 / 独立访客 / 威胁拦截 / 错误率
  ─ 以下维持现有分区：图表区 / 补充指标 / 下钻 Top20 ─
```

要点：`总请求` 与它的 sparkline 合成"主表盘"一块卡，占首屏上半；错误率因为 §9 实测常年越线，放副表盘最后一格但用 `bad` 轨色，扫一眼先看到坏消息；其余 3 格（HTTPS 率、明文数、平均体积）收进"副表盘·第二页"，默认不占屏。**只动 BoardView 装配顺序，数据请求一次不加**（首屏 1 次 /v1/overview 的预算不动）。

### 2.3 签名动作：开机自检（本轮唯一的"险棋"）

打开看板的一瞬间，所有卡片的读数轨按分区**自上而下错峰走纸**（每路延迟 60ms，单路动画 240ms），数字从千位起 flash 一次——像仪表上电自检。只在看板首屏跑一次，`prefers-reduced-motion: reduce` 时整段关闭直接落终态，刷新按钮重触发一次。理由：读数仪的"醒机"是它自己世界里的动作，不是网页的入场动画；且这正好复用 §9 已经建好的 `rail-feed`，不是从零造。

### 2.4 字阶对比拉大（眯眼改动，降级顺手项）

现有字阶 12/14/15/27 太挤。拉到 5 档：11（口径小写）/ 13（正文）/ 15（标题）/ 20（次读数）/ 44（主表盘）。`.tile-value` 27px → 次表盘 20px + 主表盘 44px；`h3` 全改 12px 大写间距眉题（eyebrow），让"分区名"和"内容"字号差变成两级而不是染色。

### 2.5 其余不动的

色板四态轨色（§9 刚定的）、数据链路与网关、路由表、文案四态措辞（`没取到/取数中/确实为空/已失效`）、长列表折叠数量、底栏五条与顺序（§12 他点的）。空态卡、ErrorNote 形状本轮保留。

## 3. 自检清单（每步改完跑，全绿才算数）

1. `vue-tsc --noEmit`、`vite build`、`npm run check:routes` 全过。
2. 浏览器 DOM 逐屏（看板/计算/数据库 D1·KV·R2 三段/域名/Zero Trust/设置）：数据还在、零控制台报错、首屏网关请求次数不变。
3. 主表盘 sparkline 有 path 节点（条形图 §13 那种"display 没写导致宽 0"的事故不允许重演：fill/stroke 的几何尺寸要用计算样式量出来）。
4. 图标：`document.querySelectorAll('svg.icon').length` 与预期格数对得上，页面里 grep 不到残留 emoji 功能图标。
5. 自检动画：注入 `prefers-reduced-motion` 模拟后轨道不动、直落终态。
6. 观感类结论（图标精不精细、自检动效烦不烦）本机拿不到视口，**留一张对比截图任务给他肉眼验收**，文档里如实写明。

## 4. 实施切分（可独立放行的小步）

- A. 图标体系（2.1）——改 `main.css` + 新 `icons.ts` + `App.vue`/动作宫格引用；
- B. 看板重排（2.2 + 2.4 的表盘字号）——只动 `BoardView.vue` 装配；
- C. 开机自检（2.3）——只动 `AsyncBlock.vue` + 一个 `st-selftest` 临时类；
- D. 全量回归 + docs/11 §15 记录。

A 独立可先行（他最可能一眼看见的就是它）；B/C 依赖彼此建议连做。每步之间工作区都保持可编译。
