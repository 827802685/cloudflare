# CF 控制台界面美化

执行前先完整读 `docs/15-界面美化方向.md`（本轮方向的唯一权威来源）和 `docs/11-实现进度与待放行部署清单.md` 最近三节（知道已经改过什么，别回退别人的成果）。

## 硬约束（违反任何一条都算改坏）

- 只动观感层：样式、排版、图标、装配顺序。**数据链路 / 网关 / 路由表 / API 方法一条不碰**。
- 文案四态措辞原样保留：「没取到 / 取数中 / 确实为空 / 已失效的选择」，不许把缺失说成 0 或"连不上"。
- 除专有名词外界面全中文；长列表默认收起前 N 条的既有实现不动。
- 首屏网关请求预算不动（看板 1 次 /v1/overview）；`WRITE_ENABLED` 状态不动。
- 令牌值（CF API Token / 设备令牌）绝不进任何输出、日志、代码。
- 不主动 commit/push，改动留工作区等用户放行。

## 实施切分（每步结束工作区必须可编译）

1. **A 图标体系**：新建 `app/console/src/lib/icons.ts`（16 格线性 SVG，stroke 1.5 / currentColor / 24 视口），替换 `App.vue` 底栏、顶栏齿轮、Worker 动作宫格与详情的 8 个 emoji；删纯装饰 emoji（标题里的 📊 这类），只删不换。
2. **B 看板首屏重排**：`BoardView.vue` 装配改「主表盘（总请求 + 32px sparkline）+ 副表盘横滑 4 格」，主表盘 44px、次表盘 20px；`.tile-value` 等字号按 docs/15 §2.4 的字阶表调。
3. **C 开机自检动效**：看板首屏卡片读数轨错峰走纸（60ms 步进 / 240ms 单路），复用 `AsyncBlock.vue` 已有的 `rail-feed`；`prefers-reduced-motion: reduce` 时整段关闭直落终态。
4. **D 全量回归 + 记录**：跑完整自检清单（下节），在 docs/11 末尾追加一节（改了什么 / 为什么 / 实测数字），docs/15 里对应条目标记完成度。

## 每步的自检清单

- `vue-tsc --noEmit`、`vite build`、`npm run check:routes` 全过。
- 浏览器逐屏 DOM 实测（看板/计算/数据库三段/域名/Zero Trust/设置）：数据仍在渲染、控制台零新增报错、首屏请求计数不变。
- 几何尺寸用计算样式量出来（条形/曲线要有非零宽高；§13 的「行内盒子 width 不生效」事故不许重演）。
- `document.querySelectorAll('svg.icon')` 数量对得上，无残留功能 emoji。

## 验收口径

用户不看对比图、扫一眼能说出至少三处不一样才算成功（docs/15 §0）。观感类结论（精不精细、烦不烦）本机浏览器拿不到可见视口，如实写明「待肉眼验收」，不许自称「效果很棒」。
